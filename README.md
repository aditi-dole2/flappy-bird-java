# Flappy Bird (Java)

A Flappy Bird clone built for a Java OOP course, focused on applying object-oriented design to game logic.

## What this does

- Implements gravity/fall physics, pipe collision detection, scoring, and a 4-lives system
- Structured as a proper Maven project (`pom.xml`, `src`/`test` layout)
- Includes a user instruction manual and flow diagrams (draw.io)

## Tech stack

Java · Maven

## How to run

```bash
mvn clean install
mvn exec:java
```

(Adjust the run command to match the actual main class once verified locally.)
